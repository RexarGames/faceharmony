# Face Harmony

Статический сайт для развлекательного анализа гармонии лица по фото.

## Что внутри

- `index.html` — разметка сайта
- `style.css` — дизайн
- `script.js` — загрузка фото, MediaPipe Face Landmarker, расчёт баллов

## Как запустить

1. Открой папку через VS Code.
2. Установи расширение Live Server.
3. Запусти `index.html` через Live Server.

Также можно залить файлы на GitHub Pages.

## Важно

Оценка условная. Сайт не определяет реальную красоту человека. На результат сильно влияют свет, ракурс, качество фото и выражение лица.
